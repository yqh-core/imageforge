Contact

ImageForge is a small open-source project maintained in spare time. There is no support desk, but we do read everything that comes in.

The best channel: the contact page

Write to us on the DigDevBox contact page. It is the most reliable way to reach us: every message gets read, and the more detail you include, the faster we can pin the problem down.

What helps us help you

A useful bug report usually contains:

  • what you did, step by step
  • what you expected to happen
  • what actually happened
  • browser and version (for example: Chrome 141 on Windows 11)
  • a screenshot, if the problem is visual
  • a sample file, if the problem depends on a particular image

Before attaching an image: crop out anything sensitive first — once sent, we cannot un-share it.

What we can and cannot do

Licensing and permissions

The software is MIT licensed, so you are free to use, modify and redistribute it without asking. That covers the code.

It does not cover the ImageForge name and logo. If you want to use the brand — for a fork, a product or a course — please open an issue first.

Privacy and data requests

ImageForge has no accounts and no database, so there is no profile to export or delete. Your images and preferences never leave your device. See the Privacy Policy for detail; if you still need something, open an issue.

Response time

No commitment — this is a volunteer project. Issues that include reproduction steps get answered far faster than "it doesn't work".
