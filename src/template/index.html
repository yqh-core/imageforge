A layer-based image editor that runs in your browser

ImageForge is a free image editor built on miniPaint. Everything happens inside your browser tab: open an image by dragging it onto the canvas, edit it with real layers, and export the result without a single byte being uploaded to a server.

Layers, undo and the tool rail

Editing is layer-based the way desktop editors are: add, reorder, duplicate and hide layers, then undo or redo any step. The left rail holds the working tool set — brush and pencil, shapes, text, crop, selection, fill, gradient, erase and a clone stamp — plus filters such as blur, sharpen and desaturate, and a magic-erase tool for backgrounds. The right panels keep the preview, colour pickers, document information and layer details one click away.

Formats you can open and export

Open PNG, JPEG, WebP, GIF, BMP and SVG — whatever your browser can decode. Export back to PNG, JPEG, WebP, GIF, BMP, or SVG for vector content. A transparent PNG stays transparent as long as you export to a format that supports alpha.

Your images never leave the device

There is no upload step because there is no server involved: decoding, editing and encoding all run locally. Once loaded, the editor also works offline, sets no cookies of its own, and stores your preferences in the browser's localStorage. The interface is available in several languages.

Do I need to install anything or sign up?

No. ImageForge runs in the browser — no install, no account, no sign-in.

Are my images uploaded anywhere?

No. All processing happens in your browser tab; nothing is transmitted to a server.

Can I use it offline?

Yes — once the editor has loaded, it keeps working without a network connection.
